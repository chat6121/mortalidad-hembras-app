¿Quieres enviarle el archivo HTML ya configurado a tus compañeros?
2. Código para tu Google Sheet (Código.gs)
  1. Abre tu hoja de cálculo en Google Sheets y ve al menú Extensiones > Apps Script.
  2. Borra lo que haya en Código.gs y pega el código de abajo.
  3. Si también deseas usar la interfaz desde el enlace web de Google, crea un archivo HTML llamado Index.html en Apps Script y pega el código de este archivo HTML.
  4. Haz clic en Implementar > Nueva implementación, elige tipo Aplicación web, en Ejecutar como selecciona Yo y en Quién tiene acceso selecciona Cualquier persona.
  5. Copia la URL generada y pégala en el recuadro de arriba.
